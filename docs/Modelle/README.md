# SeasonShift – Domänenmodell (Iteration 3)

Diese README dient als kurze Begleitbeschreibung zum Domänenmodell.  
Sie beschreibt den in Iteration 3 erreichten fachlichen Zielzustand des Systems und die darin enthaltenen Konzepte.

---

## Kontext

Das Projekt *SeasonShift* beschäftigt sich mit der raumbasierten Navigation durch zeitlich strukturierte Inhalte.  
Nutzer:innen interagieren körperlich im Raum, um zwischen unterschiedlichen Zeitpunkten und Inhalten zu wechseln.

Das Domänenmodell Version 3 bildet den finalen fachlichen Stand des Systems ab.

---

## Abgedeckte fachliche Konzepte

Das Domänenmodell Version 3 umfasst u. a.:

- Nutzer:innen / Interaktionen im Raum  
- Controller / Tracker als Eingabegeräte  
- Räumliche Zonen / Bereiche  
- Zeitliche Strukturierung der Inhalte  
- Zuordnung von Raumpositionen zu Inhalten  
- Gleichzeitige Interaktion mehrerer Nutzer
