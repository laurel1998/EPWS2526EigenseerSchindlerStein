# SeasonShift – User-Journeys

Diese README dient als kurze Begleitbeschreibung zu den User-Journeys.  
Die beschreibt was die User-Journeys sind und welche Probleme, die in den User-Journeys entstanden sind, im Projekt (nicht) behoben wurden.

---

## Kontext

Die User-Journeys sollen ein erstes Bild dafür schaffen, wie gewisse Storylines der Interaktion aussehen könnten. Dazu wurden 3 verschiedene Personas entwickelt, mit unterschiedlichen Erwartungen an das System. 

1. Person:
Mia, 26 Jahre alt, Masterstudentin
Erwartungen: 
- Überraschungseffekt 
- Lerneffekt
- System ohne Erklärung nutztbar

2. Person:
Matthias, 41 Jahre alt, Ingenieur
Erwartungen:
- Überraschungseffekt 
- Lerneffekt
- System technisch verstehen

3. Person:
Emil, 10 Jahre alt, Schüler
Erwartungen:
- Überraschungseffekt 
- Spielerisch

---

## Zusammenfassung der Erkenntnisse 

Aus den User-Journeys wird deutlich, dass die Nutzer:innen ein Feedback beim Aufheben und/oder Anschalten des Controllers erwarten würden. Dies ist technisch jedoch nicht umsetztbar.
Dieses Problem wurde damit behoben, dass die Controller bereits alle zum Start der Interaktion in der Mitte der Fläche liegen und ein Titelbild mit der Aufforderung zum Bewegen angezeigt wird. Somit wissen die Nutzer:innen was zu tun ist. 

Außerdem erkennt man in den User-Journeys, dass die Personas auch auditive Effekte erwarten. Dies war jedoch aus zeitlichen Gründen im Rahmen des Projekts nicht umsetzten.
