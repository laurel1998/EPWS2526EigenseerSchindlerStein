# Assets

Enthält Stichprobe der Bilddaten und Mapping-Datei.

Die Bilddaten und deren Mapping werden zunächst als statische Assets im Repository abgelegt. Diese Entscheidung reduziert die Komplexität im frühen Projektstadium, vermeidet zusätzliche Abstraktions- oder Bereitstellungsschichten und ermöglicht eine schnelle, nachvollziehbare Integration der Bilder in den Code.
